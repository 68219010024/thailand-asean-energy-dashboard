# แดชบอร์ดไฟฟ้าไทยและอาเซียน (Streamlit)

ข้อมูล: `data/energy_clean.csv` (คัดลอกมาจาก `final/` หลังทำความสะอาด 5 ขั้น)

## บัญชีทดสอบสำหรับกรรมการ
- ชื่อผู้ใช้: `judge`
- รหัสผ่าน: `energy2025`
(เปลี่ยนได้ที่ `.streamlit/secrets.toml` หรือ Settings > Secrets บน Streamlit Cloud)

## รันบนเครื่อง (แผนสำรองตามเกณฑ์ 3.5.5)
```
cd dashboard
pip install -r requirements.txt
streamlit run app.py
```
เปิดเบราว์เซอร์ที่ http://localhost:8501

## คู่มือย่อ (Quick guide)
1. เข้าสู่ระบบด้วยบัญชีทดสอบ
2. ภาพรวม: กราฟสำคัญทั้งหมด เลือกปีและประเทศที่ต้องการวิเคราะห์ด้านบน
3. รายประเทศ: เลือกประเทศ (พิมพ์ชื่อภาษาอังกฤษเพื่อค้นหา) และช่วงปี
4. เปรียบเทียบ: เลือกชุดประเทศ (อาเซียน ทวีป 10 อันดับแรก หรือกำหนดเอง) และตัวชี้วัด
5. ผลการวิเคราะห์: สรุปผลการศึกษา สถิติเชิงพรรณนา การกระจาย ความสัมพันธ์ และคุณภาพข้อมูล
6. ตารางข้อมูล: กรอง ค้นหา เรียง และดาวน์โหลด CSV/Excel

## โครงสร้าง
```
dashboard/
├── app.py                         โค้ดแดชบอร์ดทั้งหมด
├── requirements.txt               ไลบรารีที่ต้องใช้
├── data/                          ข้อมูลสะอาด + data dictionary + สรุปคุณภาพ
└── .streamlit/
    ├── config.toml                ธีมสี
    └── secrets.toml.example       ตัวอย่างบัญชีผู้ใช้
```
